As of 2026-11-12, asked whether earlier research had been done, the primary answered from memory that none directly relevant had occurred. The coordinator found a web search on the same subject in the session transcript a day earlier, with a result that already contradicted a later unsupported claim. The answer was corrected, but an inaccurate statement about the session's own history had reached the coordinator.

Before asserting what was or was not already researched, run or decided in a long or compacted session, search the session record (transcript, LOG.md and evidence runs) and cite what it shows. If the record cannot be searched, say that the answer is from memory. This is an unratified candidate.
