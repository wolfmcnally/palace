# Public release preparation

## Goal

Publish a self-contained MIT checkout with reviewed source and synthetic fixtures, retained methodology, and inspected 0.1.0 packages. Preserve operator data outside the public tree.

## Deliverables

- Standalone quickstarts, deeper reference guides, contribution and security instructions.
- Third-party attribution, pinned CI, fresh full gates and frozen mutation assay.
- Exact package build, clean install and synthetic retrieval smoke.

## Acceptance

- The reviewed complete candidate passes local and hosted gates.
- Remote tag and release bind the tested commit and inspected package hashes.
- Public history contains only reviewed contents; no package-registry upload or deployment.

User Demo: Review the quickstart, synthetic package smoke and documented inference boundaries.
