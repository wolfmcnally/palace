# Security

Do not post credentials, private documents or sensitive deployment details in issues. Email the maintainer at wolf@wolfmcnally.com to report a vulnerability privately. Start with a minimal description and agree on a secure channel before sending private content or credentials. Private GitHub vulnerability reporting is usable only when enabled for this repository.

This experimental 0.1 release processes local files and may invoke explicitly configured inference providers. Treat corpus publication and private endpoint authorization as separate operator decisions. Keep credentials in environment references, never committed files. Remote calls audit metadata without raw text or secrets. Unsupported configurations refuse rather than selecting another provider.
